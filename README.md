## Projects

- **Robot Walking on a Mars Yard**  
  Reinforcement Learning to teach a simulated monopod robot how to walk on complex, Mars-like terrains. I worked on training setup, domain randomization and robustness to perturbations.

- **Pac-Man Game on ARM**  
  Pac-Man implemented in C on an ARM-based embedded board. I handled low-level game logic, input and display on constrained hardware, with a fully playable version on the real board.

- **Messaging Application in Rust**  
  Client–server messaging app in Rust with private/group chats, notifications and a simple GUI. Tested on Linux and Windows, focusing on reliability and clean architecture.

- **Distributed Control for CPS**  
  Distributed control strategies for a network of magnetic levitation systems modeled as a CPS. I implemented cooperative control and observers to achieve synchronization and trajectory tracking.
